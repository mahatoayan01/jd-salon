# JD's Unisex Salon Parel - Web Application

A modern, conversion-focused responsive website for **JD's Unisex Salon**, Bhoiwada, Parel, Mumbai.

## How to Edit Site Content & Deploy
1. **Edit Site Data**: All salon info, services, pricing, opening hours, team, reviews, and images are managed in a single file: `src/data/siteData.js`.
2. **Install Dependencies**: Run `npm install` in the project root.
3. **Local Development**: Run `npm run dev` to preview changes at `http://localhost:5173`.
4. **Production Build**: Run `npm run build` to generate the production-ready static assets in the `dist/` directory.
5. **Static Hosting**: Deploy directly to Vercel, Netlify, or Cloudflare Pages with single-page application fallback (pre-configured with `vercel.json` and `public/_redirects`).
